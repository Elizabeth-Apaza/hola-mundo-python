# Hola Mundo - Lectura de Números en Python

Repositorio de prueba para verificar la conexión con GitHub, la ejecución de Python y la lectura de datos por consola.

## Funcionalidad
El script solicita al usuario que ingrese un número por teclado, valida la entrada y determina si el número es positivo, negativo o cero.

## Requisitos
- Python 3.x

## Ejecución
Para ejecutar el script:

```bash
python main.py
```

## Ejemplo de uso
```text
=== Programa de Lectura de Números ===
Por favor, ingresa un número: 42
✅ Has ingresado el número: 42
El número es positivo.
```
